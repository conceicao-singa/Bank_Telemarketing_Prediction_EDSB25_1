# Bank_Telemarketing_Prediction_EDSB25_1

## A comprehensive machine‑learning project focused on predicting whether a customer will subscribe to a term deposit following a bank’s telemarketing campaign. Special emphasis is placed on false negative reduction, campaign insights, and robust model evaluation.

This project aims to clearly address the challenge of accurately predicting long‑term deposit subscriptions by following a structured path: understanding customer behavior, preparing clean and leakage‑free data, engineering meaningful features, and developing models that perform reliably in real-world campaign settings.
